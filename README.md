# Smart Attendance — AI Risk Prediction

A student self-service attendance tracker with AI risk prediction.
Students register themselves, upload their attendance (CSV/XLSX) or
enter it manually, and instantly see their overall percentage, per-subject
breakdown, a what-if planner ("how many classes must I attend to hit 75%?")
and an ML risk prediction (SAFE / WARNING / HIGH RISK).

**No admin role.** Every student manages only their own data.

## What it does

- JWT auth: register, login, forgot-password, profile edit
- Attendance upload (CSV/XLSX) + manual entry + edit/delete subjects
- Dashboard: stat cards, overall progress bar, per-subject bar chart, subjects table
- Analytics: attendance-by-subject bar chart + attended-vs-absent pie chart
- AI Prediction: risk level, model used, recommendation, feature values, model comparison
- What-If Planner: pick a target % (60–90) and see classes to attend / classes you can miss
- Reports: on-screen summary + CSV and PDF downloads

## Tech stack

- **Frontend:** React 18 + React Router 6 + Recharts, Vite 5
- **Backend:** FastAPI + SQLAlchemy/SQLite, JWT auth
- **ML:** scikit-learn — Logistic Regression, Random Forest, Decision Tree
- **AWS:** S3, Lambda, DynamoDB, SageMaker, IAM (manual setup, see below)

## How to run locally

Prerequisites: Python 3.10+ and Node.js 18+.

```powershell
# 1. Backend + ML (from the project root)
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r backend\requirements.txt
pip install -r ml\requirements.txt
python ml\generate_dataset.py
python ml\train.py
python -m pytest tests\ -v

# 2. Start the backend (from the project root)
uvicorn backend.app.main:app --reload --port 8000

# 3. Frontend (new terminal, from the project root)
cd frontend
npm install
npm run dev
```

Open http://localhost:5173, register a demo user
(email `demo@student.com`, password `Demo@1234`), then upload
`data/sample_attendance.csv` from the Upload page.

Full Windows step-by-step: see [DEPLOY_WINDOWS.md](DEPLOY_WINDOWS.md).

## ML honesty note

- The training dataset is **synthetic** — generated by `ml/generate_dataset.py`
  (attendance %, previous-semester %, assignments done, internal marks -> risk label).
- Model metrics are **real measured values** on that synthetic data and are
  written to `ml/evaluation.json` by `ml/train.py`. Read that file for the
  actual numbers.
- **No accuracy is invented or claimed** in this README, the UI, or the docs.
  The models predict risk on synthetic patterns only; they are a college
  mini-project demonstration, not a production risk system.

## AWS manual steps (summary)

The app runs fully locally without AWS. To move the data/ML path to AWS:

1. Create S3 bucket `<BUCKET>` and DynamoDB tables from `aws/dynamodb-schema.json`.
2. Attach `aws/iam-policy.json` (replace `<BUCKET>` / `<ACCOUNT>`) to a Lambda role.
3. Deploy `aws/lambda/process_upload.py` as a Lambda triggered by S3 uploads.
4. Train on SageMaker with `aws/sagemaker/train_sagemaker.py`.

Full checklist: `aws/ARCHITECTURE.md`.
